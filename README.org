** 使用方法

使用git clone下载项目到本地

#+BEGIN_SRC
  git clone https://github.com/Lioyae/nn_mnist.gitg
#+END_SRC

#+BEGIN_SRC
  clang --target=x86_64-w64-windows-gnu xxx.c -o xxx.exe -lm
